# WordPress Cost Calculator Builder Skill

An autonomous AI agent skill to generate high-converting, localized, standalone WordPress cost calculator widgets (HTML/CSS/JS) based on minimal user inputs.

## 📌 Features

- **Localized Cost Baseline**: Grounded in real local trade labor rates ($/hr), materials, and building code standards (e.g., Grass Valley, CA / Nevada County).
- **Standalone Snippets**: Generates dependency-free HTML/CSS/JS code snippets compatible with WordPress Gutenberg, Elementor, and Divi.
- **5-Second Auto-Close/Minimize Card**: Interactive results card with countdown badge, hover pause, and manual minimize toggle.
- **Visual & Line-Item Breakdown**: Includes itemized subtotal tables, visual stacked progress bars, and print/PDF estimate triggers.
- **Minification Engine**: Includes Python automated minification for super-fast loading.

## 🛠️ Minimal Inputs Required

- **Location**: Target city & state (e.g., `Grass Valley, CA`)
- **Calculator Keyword**: Target SEO Keyword (e.g., `Shower Enclosure Installation Cost Calculator`)
- **Color Palette**: 3 Hex Codes (Header/Button, Background, Text)
- **Font Family**: Google Font or web font stack (Default: `'Oxygen', sans-serif`)
- **Container Width**: Max-width constraint (Default: `max-width: 100%`)
